# Rating System — оценка постов

Цель рейтинга — не гнаться только за просмотрами, а понимать, какие публикации создают **интерес, доверие, обсуждение и конверсию**.

## Когда оценивать
- T+24h — первичная реакция;
- T+72h — основная органическая волна;
- T+7d — стабильный результат;
- T+30d — long-tail и итог.

## Базовые показатели
1. `View Rate = Views / Subscribers at publish × 100%`
2. `Reaction Rate = Reactions / Views × 100%`
3. `Comment Rate = Comments / Views × 100%`
4. `Forward Rate = Forwards / Views × 100%` — если доступно.
5. `Subscriber Gain` — прирост, связанный с публикацией/серией.
6. `Boosty CTR = Boosty clicks / Views × 100%` — если CTA был на Boosty.
7. `Qualified Feedback` — полезные вопросы/кейсы/технические комментарии.

## Итоговый рейтинг 0–100
До накопления собственной статистики использовать относительную шкалу внутри канала:
- 30% — View Rate;
- 20% — Reaction Rate;
- 15% — Comment Rate;
- 10% — Forward/Share Rate;
- 10% — Subscriber Gain;
- 10% — Qualified Feedback;
- 5% — целевая конверсия (если была).

Показатели нормализуются относительно медианы последних 10 сопоставимых постов.

## Классы
- `S` — 90–100: сильнейший материал, масштабировать механику.
- `A` — 75–89: успешный, повторять тему/формат.
- `B` — 60–74: нормальный рабочий пост.
- `C` — 40–59: нужен разбор причины.
- `D` — <40: не повторять без существенного изменения.

## Важное правило
Нельзя сравнивать напрямую:
- закреп/навигацию с обычным постом;
- рекламный пост с технической серией;
- пост с внешним трафиком с чисто органическим.
Сравнение делать по типам/сериям.
