# Media per post

Для каждого поста создаётся папка `POST-XXX/`.

Пример:
```
POST-003/
  POST-003_01_original.jpg
  POST-003_01_tg.jpg
  POST-003_02_original.jpg
  manifest.md
```

`manifest.md` содержит:
- MEDIA-ID;
- что изображено;
- источник;
- можно ли публиковать;
- где уже использовано;
- подпись/alt-текст;
- контроль повторного использования.
