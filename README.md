# Память проекта «AI для инженера»

Эта папка — единая долговременная память проекта Telegram → аудитория → Boosty.

## Основной рабочий цикл
`INDEX → STATUS → DECISIONS → CONTENT → POSTS → MEDIA → METRICS → CHANGES → TESTS → STATUS`

## Что где хранится
- `INDEX.md` — главная карта памяти проекта.
- `STATUS.md` — текущее состояние проекта и ближайшие действия.
- `DECISIONS.md` — принятые решения и причины.
- `content/` — стратегия, рубрики, контент-план и правила публикаций.
- `posts/` — архив всех постов и черновиков.
- `media/` — оригиналы изображений/обложек и связь с постами.
- `metrics/` — статистика публикаций, рейтинг и методика оценки.
- `changes/` — журнал существенных изменений проекта.
- `bugs/` — ошибки процесса/контента и способы устранения.
- `tests/` — проверки перед публикацией и периодические ревью.
- `refs/` — исходные ТЗ, брендбук и другие опорные материалы.

## Главное правило архива постов
После публикации текст поста сохраняется **в исходном опубликованном виде без редактирования** в `posts/published/.../original.md`.
Если Telegram-пост позже отредактирован — первоначальный файл не меняется. Новая версия сохраняется как `revision-01.md`, `revision-02.md` и т. д.

К каждому опубликованному посту сохраняются:
1. исходный текст;
2. дата/время и ссылка/ID;
3. все использованные изображения/видео в исходном виде;
4. метрики через 24 ч / 72 ч / 7 дней / 30 дней;
5. итоговый рейтинг;
6. вывод: повторять формат / тестировать / не повторять;
7. ключевые темы и фразы — для защиты от повторов.
